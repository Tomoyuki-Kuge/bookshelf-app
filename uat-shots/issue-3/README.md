自動テストの追加データはトランザクションで取り消した。画面確認準備の投入データは、一時コンテナ内に保存した今回の作成ID一覧と業務7表の現在ID集合が一致することを確認し、そのIDの行だけを削除した。終了後の業務7表は各0件。一時HTTPコンテナは停止・削除済み。既存サービス・ボリュームは維持した。
