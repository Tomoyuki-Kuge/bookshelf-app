## 遷移停止の追加調査と再試行

- ログアウト→山田太郎で再ログイン→同じカードのクリックを行うと、再び一覧に留まった。ログイン直後の状態で再現した。
- リンクのDOMは正しい詳細URLを持つ通常のa要素で、クリック位置に別の要素が重なっている状態ではなかった。
- アプリコンテナのHTTPログには、停止中のクリックに対応する新しいアクセスがなかった。ブラウザコンソールにもJavaScriptエラー・警告はなかった。
